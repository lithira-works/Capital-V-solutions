=========================================
  Capital V Solutions – Hero Video Guide
=========================================

Place your video file in this folder with the name:

  hero.mp4   (recommended – best browser compatibility)

Or alternatively:
  hero.webm  (smaller file, modern browsers)

The HeroVideo component will automatically pick it up from:
  /videos/hero.mp4

Recommended video specs:
  - Resolution : 1920 × 1080 (Full HD) or higher
  - Format     : MP4 (H.264 codec)
  - Duration   : 15–60 seconds (will loop seamlessly)
  - File size  : Under 30 MB for best performance
  - Audio      : Not needed (video plays muted)

Once you drop your file here, refresh the page to see it live.
